VirusTotal Scanner

Программа для проверки файлов на вирусы через сервис VirusTotal.

Возможности

Проверка файла по хешу SHA-256
Загрузка файла на сервер если его нет в базе
Просмотр статистики обнаружений по антивирусам
Просмотр комментариев пользователей VirusTotal
Просмотр рейтинга сообщества файла
Настройка языка интерфейса русский и английский
Настройка темы светлая и тёмная
Звуковое уведомление по завершении проверки
Счётчик использованных запросов к API с ежедневным сбросом

Установка

Скачать exe файл из раздела Releases и запустить.
При первом запуске нужно ввести свой API ключ VirusTotal.
Получить ключ можно бесплатно на сайте virustotal.com после регистрации.
