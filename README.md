# VirusTotal Scanner Pro

Бесплатная программа для проверки файлов через VirusTotal.

## Что умеет

- Проверяет любой файл (EXE, DLL, PDF, DOC, ZIP и другие) через базу VirusTotal.
- Показывает полный отчёт: какие антивирусы сработали, статистика, репутация, комментарии.
- Если файла нет в базе — загружает его на проверку и ждёт результата.
- Работает с бесплатным API-ключом VirusTotal.

## Как пользоваться

1. **Получить API-ключ** на [virustotal.com](https://www.virustotal.com/gui/join-us)) (бесплатно, 500 проверок в день).
2. **Ввести ключ** при первом запуске программы.
3. **Выбрать файл** — нажать кнопку "Выбрать файл".
4. **Дождаться результата** — программа покажет отчёт.

## Настройки

В меню "Действия" можно:
- Сменить API-ключ
- Включить/выключить звук
- Сменить тему (тёмная/светлая)
- Сменить язык (русский/английский)
- Включить режим "поверх всех окон"

## Важно

- Бесплатный тариф VirusTotal — 500 запросов в день. Счётчик показывает, сколько вы уже потратили.
- На проверку большого файла может уйти до 7 минут — просто подождите.
- Результаты хранятся в папке `%LOCALAPPDATA%\VirusTotalScanner`
