# VirusTotal Scanner Pro — C++ / Dear ImGui + DirectX 11

Портирован с оригинального Python/customtkinter-приложения (`virustotal.py`) на нативный
Windows-десктоп: Dear ImGui поверх DirectX 11 + Win32, без Python-рантайма.

## Что сохранено из оригинала

- Проверка файла по SHA-256 в базе VirusTotal, при отсутствии — загрузка и опрос анализа.
- Полный отчёт: статистика (harmless/undetected/suspicious/malicious/timeout), список
  сработавших антивирусов с методом детекта, репутация файла, голоса сообщества, комментарии.
- Кнопка «Проверить сейчас» во время ожидания анализа.
- Настройки: тема (тёмная/светлая), звук по завершении, тип API-ключа, язык (RU/EN),
  «поверх всех окон», счётчик использованных запросов за день (сбрасывается ежедневно).
- Диалог ввода/смены API-ключа, копирование хеша, открытие отчёта в браузере.
- Конфиг хранится в `%LOCALAPPDATA%\VirusTotalScanner\vt_config.json` — как и раньше.

## Ключевые особенности C++-версии

### Безопасное хранение API-ключа
- Ключ шифруется через Windows DPAPI (`CryptProtectData`/`CryptUnprotectData`) перед сохранением в конфиг.
- Хранится в base64-кодированном зашифрованном виде.

### Асинхронное сканирование
- Вычисление SHA-256, HTTP-запросы и ожидание анализа выполняются в отдельном потоке.
- Интерфейс остаётся отзывчивым на всех этапах.

### Надёжная работа с API
- Автоматическая обработка HTTP 409 (конфликт) — извлечение ID анализа из сообщения об ошибке.
- Повторные попытки при ожидании завершения сканирования (до 30 попыток с интервалом 15 секунд).
- Таймауты и детальная диагностика сетевых ошибок.

### Полноценная локализация
- Полная поддержка русского и английского языков.
- Корректное отображение кириллицы в интерфейсе.

### Улучшенный пользовательский опыт
- Прогресс-бар на всех этапах: вычисление хеша, проверка в базе, загрузка, ожидание анализа.
- Структурированный вывод с разделением на статистику, обнаружения, репутацию и комментарии.
- Кнопка «Проверить сейчас» для ручного обновления статуса анализа.

## Чего нет (сознательно упрощено при портировании)

- Иконки эмодзи заменены на текстовые пометки (`[M]`/`[S]`, `!!`, `===`) — стандартный
  шрифт Dear ImGui/Segoe UI не рендерит цветные эмодзи.
- Системный трей и автозапуск с Windows не реализованы (были заглушками и в оригинале).
- Диалог "Спасибо за скачивание" не перенесён.

## Архитектура

Проект построен на следующих модулях:

- **App** — ядро приложения, управление состоянием и UI-логикой.
- **HTTP Client** — HTTPS-клиент на WinHTTP для работы с VirusTotal API.
- **Config** — загрузка/сохранение настроек с шифрованием API-ключа.
- **SHA-256** — собственная реализация хеширования файлов.
- **Lang** — система локализации (RU/EN).

Все модули используют только стандартную библиотеку C++ и Windows API, без внешних зависимостей.

## Первый запуск

При первом запуске, если API-ключ не сохранён, сразу откроется диалог его ввода.
Бесплатный ключ можно получить на https://www.virustotal.com/gui/join-us — учтите лимиты
бесплатного тарифа (4 запроса/мин, 500/день), они не проверяются программой на лету,
только отображается локальный счётчик использованных запросов.
